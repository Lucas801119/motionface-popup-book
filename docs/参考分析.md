# 参考分析与实现边界

参考页面：https://motionface.cc/?recording=ad1b3f0a-1770-4743-a28f-9a7ad9c378af

片段标识：`ad1b3f0a-1770-4743-a28f-9a7ad9c378af`。

## 输入与分析方法

从用户提供的临时地址下载参考视频，仅在项目外层 `assets/reference.mp4` 保留原文件；签名地址和绑定凭证不进入源码。使用 ffprobe 检查媒体参数，ffmpeg 每秒抽帧查看全片构图与字幕，另外制作每隔两秒的总览。

ffprobe 的实际结果：1920×1080，30 fps，1146 帧，38.2 秒，H.264 视频与 AAC 双声道音频。时间轴和输出规格据此设置，不是估计值。

## 视觉选择

- 构图：舞台式中央书册、俯视桌面、前景标签和底部独立字幕。
- 色彩：棕色桌面、墨绿封面、米黄色纸张，红绿蓝紫黄作为分类强调色；色值为视觉匹配选取，并非原项目参数。
- 字体：参考呈现宋体/衬线风格；本工程通过 Fontsource 打包 Noto Serif SC，避免依赖本机中文字体。原片实际字体名称未确认。
- 动效：逐帧计算位置、缩放、折叠高度、透明度与镜头缩放；不使用浏览器实时 CSS 动画，不依赖随机时钟。
- 材质与光照：SVG 路径、投影、渐变和程序纹理近似纸模型效果。

## 如实说明

这是可编辑的程序化复刻，不是像素级一致的原始三维场景。原片更细的木纹、真实折纸透视、纸偶细节、运动模糊及复杂灯光只做了近似；分镜插画为重新绘制的几何图形。字幕时间按画面观察匹配，未获得原工程字幕文件。

画面完全由 React/SVG 绘制，没有以参考视频或逐帧截图作为背景播放。音轨从用户指定参考片中无重编码提取，用于保持本次复刻的旁白和节奏；音轨权利仍属于原权利人，仓库不对其另行授予许可。字体遵守其依赖包附带的 OFL 许可。
